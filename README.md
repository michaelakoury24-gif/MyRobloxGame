# Island Valley Terrain

A Rojo-powered Roblox landscape that replaces the football project with terrain only.

## Included terrain

- Smooth grass island surrounded by bright blue ocean water
- Rounded, grass-covered cartoon mountains around a playable central valley
- Terrain-water waterfall and valley stream
- Four floating rock-and-grass islands
- Soft terrain shaping with reduced noise and no rough grass decoration
- Invisible central spawn point (no baseplate or football objects)

The map is generated by `src/server/init.server.luau` when Play starts. It clears the old football map, baseplate, and existing Workspace terrain before creating the island.

## Project layout

- `src/server/init.server.luau` — terrain generation and safe player spawn
- `default.project.json` — Rojo place mapping with no baseplate or football assets
